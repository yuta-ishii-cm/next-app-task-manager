# next-app-task-manager

Claudeと一緒にNext.jsを学ぶ演習教材です。タスク管理アプリを作りながらNext.jsの基礎を身につけます。

## ドキュメント

https://yuta-ishii-cm.github.io/next-app-task-manager/

## コンテンツ

- **Phase 1** - 基礎編（App Router、ルーティング、Server/Client Component）
- **Phase 2** - UI構築編（コンポーネント設計、TypeScript、Tailwind CSS）
- **Phase 3** - データ操作編（useState、フォーム、Server Actions）
- **Phase 4** - 完成編（Prisma、CRUD、デプロイ）
- **Optional** - 発展課題（ドラッグ&ドロップ、楽観的更新など）

## ローカルで起動

```bash
cd practice
pnpm install
pnpm doc:dev
```
